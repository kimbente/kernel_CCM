# sigCCM

The experiments can be reproduced by running the three `.ipynb` notebooks. We also saved our results as torch tensor in the `resuls` folder. 

# Requirements

We used the following packages and versions. 

numpy     : 1.24.1  
pandas    : 2.1.3  
plotly    : 5.9.0  
torch     : 2.1.1+cu118  
matplotlib: 3.7.2  
Python implementation: CPython  
Python version       : 3.11.3  
IPython version      : 8.18.0  

Furthermore we use the **sigkernel** package [link to Github](https://github.com/crispitagorico/sigkernel) and code for **IAAFT** [link to github](https://github.com/mlcs/iaaft/blob/main/iaaft.py).
